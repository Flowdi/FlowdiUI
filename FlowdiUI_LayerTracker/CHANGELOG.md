# Changelog

## 1.0.0

- Initial standalone release for World of Warcraft: Forever.
- Detects the current outdoor layer from visible NPC GUIDs.
- Tracks recently observed layers by realm, faction, and zone.
- Exchanges validated observations with compatible users through guild, group, whisper, and local yell addon traffic.
- Includes the compact FlowdiUI panel, tooltip, settings window, mover, persistence, and slash commands without external dependencies.
